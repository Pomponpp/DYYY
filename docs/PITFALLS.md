# DYYY 踩坑登记（PITFALLS）

> 每条都对应一次真实的构建失败、真机崩溃或功能全灭。
> 改代码前扫一眼，能省掉一整天的排查。

---

## 1. `%hook` 不吃宏 —— 类名集中化只能用"生成"或"常量"

**做法（错误）**

```objc
#define DYYY_T_FeedTableView AWEFeedTableView
%hook DYYY_T_FeedTableView      // ← 展开成 %hook DYYY_T_FeedTableView 字面量
```

**后果**：Logos 预处理器对 `%hook` 后跟的 token 不做宏展开，直接当作类名字符串。
一次全项目批量替换 321 处 → **739 个 hook 全部挂空，所有功能消失，启动不报错**。

**正确做法**

- 类名集中只能放在 **字符串常量 / 函数返回值**（如 `DYYYClassNamed(@"...")`、`DYYYResolveSwiftClass()`）
- `%hook` 目标类必须写字面量
- 想减少重复，用代码生成脚本产出 `.xm`，而不是宏

**自检手段**：装包后看日志里 `hook 生效数`；如果远小于期望值，就是这一类问题。

## 2. 全局副作用必须限定作用域

**案例**：HDR 亮度限制用"亮度突变检测"判断 HDR 视频，结果**普通视频也被压暗，全站亮度异常**。

**规则**：任何"改系统状态""改全局视图""截全局手势"的逻辑，必须满足至少一条：

- 绑到具体实例（播放器对象 / 页面控制器）
- 用页面类型白名单
- 有独立开关且默认关闭

## 3. 诊断导出连崩 4 版的三个真因

| 版本 | 崩溃点 | 根因 |
|---|---|---|
| #36 | `presentViewController` | 从一个正在转场的 VC 上 present |
| #37 | 后台线程写文件 | `writeToFile` 在非主线程 + 后台时机 |
| #38 | `closeFile` 后继续写 | 文件句柄提前关闭 |
| #39 | 重试逻辑自锁 | 重试时重复 present |

**收敛做法（最终形态）**

```
采集（主线程同步取快照）
  → 序列化到 NSData（内存）
  → 写 App 容器 tmp（后台串行队列）
  → 主线程异步回调弹分享
```

**禁止**：主线程 `dispatch_sync`、在 viewDidDisappear 之后 present、文件句柄跨线程共用。

## 4. 大范围删除必须"外层 → 内层"

**案例**：清理 887 行 HDR 死代码。第一版先删被调用的工具函数，留下 40+ 处悬空调用 → 编译全炸。

**规则**

1. 先列出函数的所有调用点（`grep -c`）
2. 只删"调用点为 0"的最外层
3. 删完立刻重新统计，再进下一层
4. 每批编译验证，不攒到最后

## 5. 主线程回调里不要 `dispatch_sync(main_queue)`

**案例**：设置页点"导出诊断包" → 直接卡死。点击回调本身在主线程，`dispatch_sync` 等自己 → 死锁。

**规则**：主线程上下文里用 `dispatch_async`，或直接执行。

## 6. 全屏：禁止逐帧改写 view 的 frame

**现象**：画面定格、弹幕照滚、点暂停再播放才恢复。

**根因**：外部每帧写媒体容器 frame → 打断 Metal 渲染管线 → 渲染停摆但 UI 层还在跑。

**规则**

- 不要在 `layoutSubviews` 里"事后修正" frame
- 要在**抖音写入的那一刻**顶回去（hook `setFrame:`，判断目标值再改）
- 一次性设定 + 不重复写

---

## 7. 全屏：不碰 `baseTableViewBottomInset`

**现象**：滑动时"拔河"——上一下视频被两股力扯。

**根因**：我们让行高 = 全窗口高，抖音内部缓存仍认为 = 窗口 − 底栏，两者每帧交替写（实测 46 次/秒）。

**规则**

- inset 不动（抖音原生 843 就让它 843）
- 行高查询**只回答、不主动改**
- 视觉补偿放在媒体容器层，不放在表/行高层

## 8. GitHub macOS runner 15 分钟硬上限

**现象**：构建跑到 15:01 被取消，**且被杀的 job 不留任何日志**（连 steps 都是空的）。

**规则**

- 单 job 控制在 15 分钟内
- 双架构（arm64 + arm64e）× 多 scheme 会超
- 缓存要覆盖 theos 安装步骤，否则光是装工具链就 7 分钟

## 9. Swift 类的 Logos 类名解析

**现象**：`%hook SomeModule.SomeClass` 编译过、运行时静默不生效。

**规则**

- Swift 类在运行时注册名是 mangled（`_TtC14AWEIMShareImpl...`）
- 准备"点号名 → mangled 名"双回退解析
- 解析失败要写日志，不要静默跳过

## 10. 版本历史靠 API 直推会制造"假未提交"

**现象**：`git status` 显示上百个未提交改动，但 `git diff origin/main` 全是 0 差异。

**根因**：发布脚本用 GitHub API 直接创建 blob/tree/commit，本地 git 索引从未更新。

**规则**

- 发布走标准 `commit → push`
- 接手时先 `git fetch && git diff origin/main --stat` 判断工作区是否只是远程的影子
